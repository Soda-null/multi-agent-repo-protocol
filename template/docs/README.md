# docs/

> **What:** Index of every file and folder under `docs/`, labelled by standing.
> **Standing:** Index. `scripts/check_doc_structure.py` fails when a file here is missing from this list.
> **How to read:** Find the file you need; open only that one.

| File or folder | Standing | What it holds |
|---|---|---|
| `agent_board.md` | Current | Claims, blocking questions, where to look |
| `decisions.md` | Ledger | Every accepted decision, with an index |
| `glossary.md` | Index | One line per code name |
| `open_questions.md` | Ledger | What is unresolved; disagreements between agents |
| `multi_agent_system.md` | Reference | Why the agents share the repository this way; routing for delegated work |
| `handoffs/` | Procedure | Packets for delegated work, and the template |
| `log/` | Ledger | One entry per working day |
