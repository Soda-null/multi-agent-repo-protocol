# Open questions

> **What:** Questions nobody may answer by guessing: what is unresolved, and disagreements between agents.
> **Standing:** Ledger (append-only). Only the owner closes a question.
> **How to read:** Read the index; grep the section you need.

When an agent disagrees with another agent's recorded conclusion and has no new evidence, it
writes the disagreement here instead of changing the conclusion.
