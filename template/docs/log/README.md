# Daily log

> **What:** One entry per working day: what was finished, where the evidence is, what changed, the next action.
> **Standing:** Ledger. Entries are added to, never overwritten.
> **How to read:** Open the day you need; never read the folder whole.

Create an entry with `python3 scripts/new_log.py`; it copies `TEMPLATE.md` and refuses to
overwrite. The log is the narrative of what was done. It is not where state lives: that is
`STATUS.md`, `decisions.md` and `open_questions.md`.
